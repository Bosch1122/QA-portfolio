# Title
Кнопка Remove в каталоге не работает, товар не удаляется из корзины

## Steps
1. Открыть сайт saucedemo.com
2. Войти в аккаунт problem_user с паролем secret_sauce
3. Нажать кнопку add to cart, на одном из товаров
4. Нажать кнопку remove на том же товаре

## Expected
Нажатие Remove удаляет товар из корзины, счетчик корзины меняется на 0

## Actual
При нажатии Remove ничего не происходит: кнопка остаётся Remove, счётчик остаётся 1

## Severity
 Major. Функция сайта сломана, затруднена покупка, клиент не может убрать товар из корзины внутри каталога, только на странцие корзины
## Priority
 Medium.Обязательно к исправлению, но сейчас мешает покупке и регулированию корзины.
